# 🎬 TV Shows Hub

A modern, responsive web application for discovering and searching TV shows using the TVMaze API. Built with React, Tailwind CSS v4, and Vite.

## 🚀 Live Demo
[View Live Project](https://movie-explorer-seven-silk.vercel.app/)

## 🛠️ Tech Stack
- **Frontend**: React 18, React Router DOM
- **Styling**: Tailwind CSS v4 (Oxide engine)
- **Build Tool**: Vite
- **API**: TVMaze API (Public, no key required)
- **Deployment**: Vercel

## ✨ Features
- **Real-time Search**: Debounced search input for efficient API calls.
- **Responsive Design**: Mobile-first grid layout that adapts from phones to large desktops.
- **Detailed Modals**: View show summaries, ratings, and genres without leaving the page.
- **Error Handling**: Graceful fallbacks for missing images, ratings, or network errors.
- **Accessibility**: Keyboard navigation support (Escape to close) and screen-reader friendly labels.
